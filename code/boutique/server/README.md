# Boutique — Node + Express

Generated from the Node server `boutique` of the application
`Boutique`. Regenerated at each change of the model: edit the
model, not these files.

## Run

1. A MongoDB server: `MONGO_URL` names it (default: `mongodb://localhost:27017/db`).
2. `npm install`
3. `npm start` — the API listens on `http://localhost:3000` (`PORT` changes it).
